Settings

Spotify Account

Connect your Spotify Premium account so Simple Player can control playback and browse your library.

Not connected Connect to Spotify

This opens Spotify's real, official sign-in page in a new tab — the same one the Spotify app uses. This preview can't finish the connection afterward (there's no backend running here to catch the reply), but the real Windows app will complete it automatically and bring you back signed in.

Immersive mode

Time without interaction before the interface hides and the cover art grows.

Volume bar

Width of the touch area for raising or lowering the volume.

Interface size

Makes all text and buttons bigger or smaller. You can also hold Ctrl and scroll (or press Ctrl +/-/0), just like in a Chrome window.

Background

Tints the Now Playing screen with the cover art's dominant colors, like Spotify.

Animated Background

Slow drift animation on the background — a subtle water-like movement.

Startup

Launch Simple Player automatically when Windows starts.

This setting, along with remembering the window's position and size, only works in the real Windows app — not in this preview.

Ghost Spotify

When nothing is playing anywhere, automatically start a hidden Spotify on this computer so Play always has somewhere to go. Closes together with Simple Player.

Works with the Spotify desktop app, classic or Microsoft Store version, on the computer running Simple Player. You must be logged in to Spotify there.

Window position

Position and size are saved automatically whenever you move or resize the window. Use these if that ever doesn't seem to be happening.

Only works in the real Windows app — not in this preview.
